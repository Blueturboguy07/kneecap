# Third-Party Notices

kneecap is a fork of [`OpenCut-app/opencut-classic`](https://github.com/OpenCut-app/opencut-classic)
(MIT License; see `LICENSE` at the repo root and `NOTICE`). This file
additionally tracks:

1. Third-party **assets** bundled directly into the repo (fonts, and
   later — per plan M6/M8 — icons/stickers/sounds), which don't carry
   registry metadata the way a package dependency does.
2. A generated **license inventory of the npm/Bun dependency tree**
   (`bun.lock`), so "what licenses does this app ship with" has one

   an archived upstream).

This is a living document. It is expected to grow as later milestones
(e.g. M6's curated font/icon work, M9's native-side dependencies) add
more.

**Two copyleft (LGPL) packages are in the tree and worth naming
explicitly rather than leaving them to scroll by inside the collapsed
"LGPL-2.1"/"LGPL-3.0-or-later" groups below:**

- **`soundtouchjs@0.3.0`** (LGPL-2.1) — the pitch-preserving time-stretch
  library backing `retime/audio-stretch.ts` (plan §M8 "Speed... Maintain
  Pitch"). Used unmodified as a library dependency (dynamic linking via
  normal ES module import, no source embedded/forked into this repo),
  which is the case LGPL's linking exception is meant for — but this is
  a "get it reviewed before shipping a binary that bundles LGPL code"
  flag for whoever does M13's build packaging, not a green light asserted
  here.
- **`@img/sharp-libvips-darwin-arm64@1.2.4`** (LGPL-3.0-or-later) — a
  platform-specific native binary for Next.js's optional build-time image
  processing (`sharp`). Same posture: unmodified, dynamically loaded,
  needs a real look at M13 packaging time, not asserted-safe here.

This inventory covers the **npm/Bun (JS/TS) tree only.** The Rust crates
(`rust/crates/*`, `rust/wasm`) are a separate ecosystem tracked via
`Cargo.lock`/`cargo metadata`, which needs `cargo` on `PATH` to enumerate
license fields — **not yet audited** (also flagged in `docs/DECISIONS.md`
and risk register #6). Whoever picks up the M1/M9 native-bridge work,
which touches the Rust workspace directly, should close this before M13
ships a real binary.

## Native (non-npm) mobile dependencies — M10 on-device captions

Neither of the two items below is actually vendored/embedded in the build
yet as of M10 part 1 (see `apps/mobile/{ios,android}` for the current
"written, not wired in" status) — recorded here now, ahead of that,
because both are referenced by name and by URL from code already in this
repo (`scripts/download-whisper-model.sh`,
`android/app/src/main/cpp/kneecap_whisper_jni.cpp`), and this document's
own stated purpose is to have one answer to "what licenses does this app
ship with" rather than requiring someone to re-derive it later.

- **`ggml-org/whisper.cpp`** — MIT. Planned integration: native plugin,
  iOS (Metal/Core ML via `whisper.xcframework`, not yet embedded) and
  Android (JNI, `libkneecap_whisper.so`, not yet built — see
  `WhisperJNI.java`'s and `kneecap_whisper_jni.cpp`'s doc comments for
  exact status).
- **OpenAI Whisper model weights** (`ggml-tiny.en.bin` / `ggml-base.en.bin`,
  fetched from `huggingface.co/ggerganov/whisper.cpp` at build time by
  `scripts/download-whisper-model.sh`, never committed — see that script's
  header comment) — MIT (the `openai/whisper` repo's own declared
  license for the original model weights the GGML conversion is derived
  from).

Both are MIT, consistent with every other dependency in this tree.
